# Day 16 — Streamlit inference demo

## Purpose and status

The repository now includes a Streamlit interface for the existing guarded inference pipeline. It accepts a **trusted** fitted joblib model bundle and a pot-level spectral CSV, runs the same date-specific validation used by `scripts/predict.py`, displays predictions and permits a CSV export.

The UI smoke test does not establish scientific validity. No real-data model artifact is available yet, so this interface is not evidence of disease-detection performance or forecasting.

## Run

From the repository root:

```bash
python -m pip install -r requirements.txt
python -m pip install -r demo/requirements.txt
streamlit run demo/app.py
```

## Input contract

- Use a model bundle generated by `scripts/train_baseline.py` or another trusted, reviewed source.
- The CSV must contain one row per inference unit/pot, the configured date field and all spectral features expected by the model.
- Only the model's exact training date is accepted.
- Date, pot identifiers and target metadata must not be model features.
- Aggregate sides/leaf ROIs to the independent inference unit before uploading.
- The demo displays the semantic distinction recorded in the model bundle and explicitly states that it is not a future forecast.

## Security

Joblib/pickle deserialization may execute arbitrary code. Only upload model artifacts from a trusted source. The demo does not claim that arbitrary model uploads are safe.

## Research limitations

The model artifact, labels, ROI registration, wavelength axis and acquisition date must be validated against the real dataset before this demo is used to communicate any biological findings. The app is a software interface to a model; it is not a plant-health diagnosis or recommendation.
